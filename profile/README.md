# CPNMR - Portuguese Nuclear Magnetic Resonance Centre

The **Portuguese NMR Centre (CPNMR)** is hosted at the [University of Aveiro](https://www.ua.pt/en/cpnmr), Portugal. This Github organization collects open-source software, workflows, data and documentation developed by and for the CPNMR community.

🌐 **Website:** <https://www.ua.pt/en/cpnmr>

## About

CPNMR provides access to nuclear magnetic resonance (NMR) spectroscopy for researchers in academia and industry, covering both solution-state and solid-state NMR.

Learn more about our [research lines](https://www.ua.pt/en/cpnmr/groups) and [available instrumentation](https://www.ua.pt/en/cpnmr/instrumentation)

## What you'll find here

- 🧪 **Software & tools** - scripts and utilities for NMR data processing, simulation and analysis
- 📊 **Workflows & data** - reproducible pipelines and example datasets
- 📚 **Documentation & tutorials** - guides for users of the centre's facilities
